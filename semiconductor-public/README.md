# 半導體公開年度排放資料補充包

資料來源：環境部氣候變遷署 GHG_P_01「溫室氣體年排放量」。
官方資料說明：https://data.gov.tw/dataset/16059
官方欄位說明：https://data.moenv.gov.tw/dataset/detail/ghg_p_01
授權：https://data.gov.tw/license（政府資料開放授權條款第 1 版）

本包不是隨機示範資料，也不是電子廠通用排放係數。資料擷取時間、分頁筆數及 SHA-256 見 source.json。這是當次下載快照，之後官方可能更新或修正。

## 檔案

- semiconductor-official-annual.csv：從官方資料依行業代碼 2611、2612、2613 篩出的 874 筆紀錄，保留原欄位和值；這是擷取後子集，不是原始 HTTP 回應的逐位元副本。
- semiconductor-clean-annual.csv：通過以下檢核的 270 筆年度廠級紀錄。
- excluded-records.csv：其餘 604 筆及逐筆排除原因。缺值不補零，也不把缺值說成申報錯誤。
- source.json：來源、擷取時間、數量及下載分頁雜湊。
- SHA256SUMS.txt：本包 CSV 的檔案雜湊。
- annual_model.py：獨立年度模型訓練及評分工具。沒有附訓練好的模型。
- requirements.txt：模型工具套件版本。

## 清理規則

1. 行業代碼與行業名稱一致：2611 積體電路製造業、2612 分離式元件製造業、2613 半導體封裝及測試業。
2. check_yn 必須為「是」。這只表示官方欄位標示已查證，不代表已取得異常分類的正確標籤。
3. 直接、間接、總排放量必須都有非負有限數字。
4. 直接加間接與總量的差距不得大於 0.002 tCO2e。這是本次資料品質檢查的選定容差，不是政府規定的容許誤差。
5. 必須有 controlno。已檢查年度＋controlno 不重複。

排除原因可重疊：604 筆缺少或無法解析直接排放量；其中 479 筆另缺少間接及總量。另有 1 筆行業代碼與名稱不一致，5 筆未標示已查證；這些紀錄也已包含在排除筆數內。

## 可用資料量

| 行業 | 2023（民國112） | 2024（民國113） | 合計 |
|---|---:|---:|---:|
| 2611 積體電路製造 | 79 | 82 | 161 |
| 2613 半導體封裝及測試 | 51 | 54 | 105 |
| 2612 分離式元件製造 | 2 | 2 | 4 |

不要把三種行業混成同一種製程。2612 樣本太少，本工具拒絕訓練。

## 執行（Python 3.12）

請在本包資料夾開啟終端機。已有原專案虛擬環境者可沿用相同套件；以下 python 請改為你的虛擬環境 Python，例如 Windows 的 .venv\Scripts\python.exe，或 macOS/Linux 的 .venv/bin/python。

```bash
python -m pip install -r requirements.txt
python annual_model.py train --input semiconductor-clean-annual.csv --industry 2611 --year 2023 --model ic-2023.json
python annual_model.py score --input semiconductor-clean-annual.csv --model ic-2023.json --year 2024 --output ic-2024-scores.csv
```

封裝測試另建模型：把 --industry 改為 2613，並使用不同模型與輸出檔名。

工具不會覆寫同名模型或輸出檔。模型保存參考樣本與參數，評分時重新建樹，不使用 pickle。模型檔為本機 JSON，並非簽章模型；請限制檔案寫入權限。它不會自動連接原系統的帳號、HMAC 或稽核 API。

## 判斷範圍與限制

特徵：log1p(年度直接排放量)、log1p(年度間接排放量)、直接排放占比。200 棵 Isolation Forest 隔離樹，random_state=42。contamination 預設 0.05，是使用者設定的預期離群比例，不是真實錯誤比例。

以 2023 訓練、2024 評分，避免把評分年度本身混入訓練。沒有已知異常標籤，不能宣稱準確率或召回率；只能觀察離群情形並人工覆核。

官方資料沒有晶圓產量、晶圓尺寸、製程節點、逐月用電量及減排設備資訊。因此大型正常工廠可能被標示為離群；此模型不能判斷每片晶圓碳效率、逐月值是否合理或證明造假。工廠級資料亦不能代表整家集團或整條供應鏈的排放。

原 CarbonGuard ZIP 的介面仍是「月份／產量」格式。本包提供獨立年度工具，不能把這份年度 CSV 直接匯入原介面的訓練欄位。未虛構產量、未將年度排放除以 12 冒充真實月資料，也未將缺值補成零。

已驗證來源筆數、清理數量、唯一鍵、非負數字、行業對應及工具的合成資料煙霧測試。尚未替使用者訓練這份真實資料或部署模型。
